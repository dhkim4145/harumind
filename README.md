# 하루마음 harumind

하루마음은 오늘 가장 가까웠던 감정을 조용히 인정하고, 잠시 머문 뒤 하루를 마감하는 감정 정리 웹앱입니다. 감정을 분석하거나 바꾸려 하기보다 오늘을 여기까지 닫는 경험에 집중합니다.

[하루마음 시작하기](https://harumind.kr/)

## 이용 흐름

1. 오늘 가장 가까웠던 감정을 하나 고릅니다.
2. 선택한 감정을 판단하지 않고 잠시 바라봅니다.
3. 화면의 문장과 머무는 자리를 따라 천천히 하루를 내려놓습니다.
4. 오늘의 마감을 확인하고 경험을 끝냅니다.

## 하루마음의 원칙

- 감정을 평가·분석·진단하지 않습니다.
- 감정 선택 기록, 완료 이력과 최근 선택 감정을 저장하지 않습니다.
- 소리는 기본적으로 꺼져 있으며 사용자가 직접 선택할 수 있습니다.
- 사용자가 선택한 소리 설정만 기기에 저장될 수 있습니다.

서비스의 데이터 처리에 관한 자세한 내용은 개인정보처리방침에서 확인할 수 있습니다.
